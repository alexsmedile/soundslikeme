# soundslikeme

Extracts your real voice from 5-10 human samples into VOICE.md and rewrites drafts to match.

## Install

### Any Agent Skills host (`npx skills`)
```bash
npx skills add alexsmedile/soundslikeme
```

### Claude Code Plugin
```bash
/plugin marketplace add alexsmedile/soundslikeme
/plugin install soundslikeme@soundslikeme
```

### Portable Agent Plugin
Conforms to the [Agent Plugins](https://agent-plugins.org) standard (`plugin.json` + `skills/soundslikeme/SKILL.md`) for Claude Code, Codex, Cursor, Antigravity, and VS Code.

## Usage
Invoke `/soundslikeme` or ask your agent directly — see [`skills/soundslikeme/SKILL.md`](skills/soundslikeme/SKILL.md).
